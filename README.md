# Cryptocurrency Market Analysis (2013-2021)

## Overview
Analysis of 23 major cryptocurrencies using historical price data from 2013 to 2021.

## Tools & Technologies
- Python 3.12
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
- Source: Kaggle - Cryptocurrency Historical Prices by SRK
- 23 coins, 37,082 rows of historical data

## Key Analyses
- Bitcoin price trend over time
- Multi-coin price comparison using log scale
- Top 10 coins by average market cap
- Bitcoin trading volume analysis
- Correlation heatmap between all 23 coins

## Key Findings
- Bitcoin dominates market cap by a significant margin
- Most cryptocurrencies are highly correlated with Bitcoin
- Tether behaves differently as a stablecoin
- Trading volume spikes during bull runs and crashesss
